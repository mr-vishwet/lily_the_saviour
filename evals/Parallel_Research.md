## 0. Headline

A fully local, **zero-download conversational** Lily is not buildable: the existing retriever can return and arrange passages, but cannot generate responses without model weights. A **$0/month memory-first Lily** is conditionally buildable with local retrieval and Groq's documented free tier, provided the owner's **free account can actually enable Zero Data Retention (ZDR)** before any personal excerpt is sent [0_headline[0]] [6][0_headline[1]] [17]. That account-level privacy test, rather than the size of a model hosted elsewhere, decides whether Lily is a private retrieval assistant or a hosted-model agent.

## 4. Three candidate stacks, ranked

**A. Zero-download, text-only** (nothing leaves the machine except nothing at all). **Privacy rank 1; conversational-quality rank 2.** Use the existing BM25, a displayed excerpt with note provenance, deterministic templates for questions it can answer, a refusal when it cannot, and the human-gated local experiment log. Added weight disk **0**, added model RAM **0**, daily API budget **unlimited/no API**, leaked content **none**; setup **roughly 1-3 hours is an unmeasured planning estimate**, not an observed benchmark. It is **not** a language-model agent. Source for starting state: owner measurements, no public URL, assessed 2026-10-05.

**B. Local retrieval + free hosted brain** (ZDR-enforced, best quality per rupee spent = 0). **Quality rank 1 only after the Groq gate passes.** Assemble a bounded persona and about eight short, non-private retrieved chunks locally; call `qwen/qwen3.8-27b` with explicit function schema, maximum tool iterations, no write actions without approval, and fall back to `openai/gpt-oss-20b` if the owner's multilingual/code eval prefers it [4_three_candidate_stacks_ranked[0]] [66][4_three_candidate_stacks_ranked[1]] [22]. Local weights **0**, local model RAM **0**, client RAM **unmeasured**, setup **about 2-4 hours estimated, not timed**, published budget **30 RPM/1,000 RPD AND 8K TPM/200K TPD**; what leaks is **the complete assembled prompt and resulting response during processing**, plus normal account/network metadata, despite enabled ZDR's retention restriction [4_three_candidate_stacks_ranked[2]] [17][4_three_candidate_stacks_ranked[3]] [6]. Groq documentation and model pages: https://console.groq.com/docs/rate-limits ; https://console.groq.com/docs/your-data ; https://console.groq.com/docs/model/qwen/qwen3.8-27b (accessed 2026-10-05). If the free account has no effective ZDR control, **do not send notes**: B is disqualified, not silently routed through an unverified alternative.

**C. Hybrid with graceful degradation** (B when online, A when off; voice added only if $0 local exists). **Practicality rank 2 after B is proven; otherwise it is A with unnecessary plumbing.** Same zero-weight base and B's quota when online; offline quota **unlimited deterministic lookups**, never local model generation. Add only a small local speech candidate *if its licence, download and peak M1 RAM pass a real test*; optional Vosk Hindi is **42 MB** and Piper Hindi voice **63.5 MB**, **plus unmeasured binaries, caches and RAM** [4_three_candidate_stacks_ranked[4]] [71][4_three_candidate_stacks_ranked[5]] [19]. Setup **about 3-6 hours estimated**, no measured figure; leaks follow B **only when B is explicitly enabled**, otherwise none. Sources: https://alphacephei.com/vosk/models ; https://huggingface.co/rhasspy/piper-voices/tree/main/hi/hi_IN/priyamvada/medium (accessed 2026-10-05).

**Decision rule:** Run the owner's *held-out* retrieval and response eval. Choose **A** when consent/ZDR fails, `private: true` exclusion cannot be demonstrated, or B's improvement in the owner's answer-quality tests is not worth disclosing even filtered excerpts; choose **B** only when ZDR is visibly active on the free account, privacy filtering passes negative tests, and its improvements survive the eval. A 2,500-token turn would exhaust a **200,000-token daily budget** after at most **80 such turns before counting any additional tokens**, even though the published RPD is 1,000; this is illustrative arithmetic, **not** a measured workload [4_three_candidate_stacks_ranked[2]] [17].

## 8. Where I disagree with your premise

- **Kokoro does list Hindi.** Absence of Marathi and absence of measured M1 peak RAM are the real blockers, not a missing Hindi voice [8_where_i_disagree_with_your_premise[0]] [21]. Source: https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md (accessed 2026-10-05).
- **A small Hindi TTS weight exists and does not consume 3.4 GB.** Piper's **63.5 MB** voice makes a constrained *experiment* reasonable; neither that file size nor a generic model-memory estimate proves this owner's concurrent-app memory use or Hinglish naturalness [8_where_i_disagree_with_your_premise[1]] [19]. Source: https://huggingface.co/rhasspy/piper-voices/tree/main/hi/hi_IN/priyamvada/medium (accessed 2026-10-05).
- **Retrieval-first is still the right default.** But a vector *store* is not the same as an *embedding model*: sqlite-vec does not supply the embeddings or a measured improvement. Test local Hinglish transliteration/query normalization and BM25 parameters against the existing eval before paying 23 MB, 471 MB or much more for a semantic experiment [8_where_i_disagree_with_your_premise[2]] [27][8_where_i_disagree_with_your_premise[3]] [36][8_where_i_disagree_with_your_premise[4]] [28]. Sources: https://github.com/asg017/sqlite-vec ; https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2/tree/main/onnx (accessed 2026-10-05).
- **Backup outranks voice.** A 2 MB private vault with no copy is a concrete single-device failure exposure; a verified restore from client-encrypted B2 has clearer benefit than any speculative TTS benchmark [8_where_i_disagree_with_your_premise[5]] [16][8_where_i_disagree_with_your_premise[6]] [4]. Sources: https://www.backblaze.com/cloud-storage/pricing ; https://restic.readthedocs.io/en/latest/070_encryption.html (accessed 2026-10-05). This is a prioritization judgment, not a claim that B2 guarantees data permanence.

## 9. Verdict

**Ship this month:** the already-working local BM25 and human-reviewed eval loop, a read-only four-tool stdlib interface, launchd scheduling, and a **restic-encrypted B2 backup with a tested restore**; enable Groq `qwen/qwen3.8-27b` only after checking the **free-account ZDR control**, an explicit private-note exclusion test and a held-out code/Hinglish eval [9_verdict[0]] [6][9_verdict[1]] [17][9_verdict[2]] [16]. At $0 it is **either** a private, deterministic text retriever **or** a conditional free-hosted agent that discloses selected non-private excerpts during inference, **not** an offline no-download conversational model, a proved natural Hinglish voice assistant, or a personal 32B fine-tune. All quoted external URLs were accessed **2026-10-05**; where the specified Mac-specific measurement or model licence was unavailable, the answer deliberately leaves the claimed fit **unverified**, rather than converting a download size into an invented RAM result.
